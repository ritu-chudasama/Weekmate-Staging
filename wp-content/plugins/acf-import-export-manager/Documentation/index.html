ACF Data Manager

ACF Data Manager is a WordPress plugin that allows you to easily export and import data from Advanced Custom Fields (ACF).

  • Created: 11/08/2025
  • Latest Update: 11/08/2025
  • By: Elsner Technologies Pvt. Ltd.

  • Export ACF Data: Export ACF field data from individual posts, all posts of a specific type, or all options pages.
  • Import ACF Data: Import ACF field data to individual posts or options pages.
  • Flexible Formats: Supports both JSON and XML file formats for export and import.
  • Overwrite Option: Choose to overwrite existing fields during the import process.
  • Mapping Interface: For "all posts" exports, the plugin provides a mapping table to link imported data with existing posts or create new ones.
  • User-Friendly Interface: A simple and intuitive admin page makes it easy to manage your ACF data.
  • ACF Dependency: The plugin requires the Advanced Custom Fields plugin to be installed and active. An admin notice will be displayed if ACF is not active.

Configuration

  1. Install the Plugin
    • Upload the plugin to wp-content/plugins/ and activate it in WordPress Admin.
    • If you're using an older version, please reset it first before using the new version.
  2. Go to ACF Data Manager Settings
    • Navigate to Tools > ACF Data Manager
  3. Exporting ACF Data
    • Select Post Type from Dropdowm
    • Select Export Options:


  4. You have 3 option for export data
    • All Posts
    • Single Post
    • Single Field Group


  5. If you select "All Posts" option, you will see a mapping table to link imported data with existing posts or create new ones when you import.
  6. If you select "Single Post" option, There is posts select drodown will appear then you need to select any post and click on inport.


  7. If you select "Single Field Group" option, There is posts select drodown will appear then you need to select any post after that based on that post field group dropdwon will appear then you need to select any option and click on import.


  8. Import ACF Data
    • Select Target Post Type from Dropdowm
    • Choose File
    • Click on overwrite existing ACF fields with the same name if you want to overwrite data
    • Click on Upload and Import button


  9. If file has all page export option then you will see mapping table, you have 3 `options` to import data map existing create new and skip.

Features

  1. Export ACF Data
    • Export ACF field data on a page-wise, post-wise, and option-wise basis.
    • Supports both JSON and XML file formats.
  2. Import ACF Data
    • Import ACF field data to individual posts or options pages.
    • Supports both JSON and XML file formats.
    • Option to overwrite existing ACF fields with the same name during import.
  3. Data Mapping
    • For "all posts" exports, the plugin provides a mapping table.
    • Helps to link imported data with existing posts or create new ones.
  4. Admin Interface
    • A simple and intuitive admin page makes it easy to manage your ACF data.
    • Includes separate tabs for Export and Import.
  5. ACF Dependency
    • Requires the Advanced Custom Fields plugin to be installed and active.
    • Displays an admin notice if ACF is not active.
  6. Easy and Hassle-Free import and export of ACF data.

Requirements

  1. You need to have ACF Plugin installed and active in both site if you are exporting and importing data in different site.
  2. You need to have ACF Data Manager Plugin installed and active in both site if you are exporting and importing data in different site.
  3. Please make sure that you have the correct permissions to access the ACF Data Manager settings in your WordPress admin panel.
  4. PLease Backup your database before performing import operations to prevent data loss in case of errors.
